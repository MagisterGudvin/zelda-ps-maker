# Анимации из PS Maker (Mana Seed и другие наборы)

С 0.7.0 Toolkit берёт анимации прямо из библиотеки PS Maker: листы, кадры, порядок направлений и коллизию персонажей вы настраиваете в PS Maker как обычно, а в действиях Toolkit только выбираете их из списков. Описывать листы и номера кадров отдельно не нужно (действия `Define Sprite Sheet`, `Define Animation`, `Preview Sprite Sheet` удалены). Ассеты наборов не входят в плагин: используйте свои купленные файлы на условиях их лицензии.

## Игрок

1. В PS Maker добавьте игроку анимации-листы, например Mana Seed *Sword Attack*, *Sword Hurt* (по строке на направление, как у ходьбы).
2. `Zelda: Set Player Sprites`:
   - **Attack** — выберите *Sword Attack* (любое направление: Toolkit возьмёт все строки листа в порядке направлений из набора анимаций игрока);
   - **Spin attack**, **Charging**, **Hurt** — по желанию;
   - **Walking while charging** — ходьба с заряженным мечом (у Mana Seed — *Sword Walk*); без неё при ходьбе с зарядом виден обычный спрайт PS Maker и встроенный клинок;
   - **Death** — смерть (последний кадр держится до возрождения);
   - раздел **Items and shield**: *Shield up* (пока зажата кнопка щита, если щит «на кнопке»), *Bow*, *Boomerang*, *Bomb*, *Hookshot*, *Use item* — для остальных предметов (жезлы, магия, свои предметы) и запасной вариант для четырёх предыдущих;
   - раздел **Lifting, pushing, chests**: *Lift* (поднять), *Carry* (нести над головой: при ходьбе анимация идёт, стоя — первый кадр), *Throw* (бросить), *Push* (толкать блок), *Item get* (поднять над головой предмет из сундука; игрок стоит секунду);
   - **Weapon layer: …** — только если оружие лежит отдельным листом поверх тела; у Mana Seed «Sword» меч уже нарисован в кадрах тела;
   - галочки *Weapon behind when facing …* — в каких направлениях слой оружия рисуется за телом;
   - *Offset X/Y* — сдвиг анимации, *Swing center X/Y* — точка, вокруг которой идёт удар.

Во время атаки и других действий Toolkit скрывает обычный спрайт PS Maker и рисует кадры поверх него, затем возвращает спрайт. Пустое поле — этот момент не анимируется, виден обычный спрайт PS Maker. Если хотят показаться несколько анимаций, побеждает важнейшая: смерть > предмет из сундука > предмет, подъём, бросок > меч > ранение > щит, нести, толкать. Длительные состояния (ходьба с зарядом, нести, толкать, щит) крутятся по кругу, разовые (предметы, подъём, бросок, предмет из сундука, смерть) проигрываются один раз (не короче 0,25 с) и держат последний кадр. Анимация растягивается на всю длительность удара (подготовка → удар → восстановление), поэтому хитбокс совпадает с кадрами. Встроенный клинок скрывается, когда задана анимация атаки (`sword.showBlade`).

## Враги

- **Look (PS Maker character)** у `Zelda: Create Enemy` (и у `Zelda: Define Enemy`) — выберите персонажа библиотеки, например *Slime*. На карту ставить его не нужно. Toolkit возьмёт его листы по названиям (`… Run`/`Walk` — движение, `Idle`, `Attack`, `Hurt`, `Death`), порядок направлений и прямоугольник коллизии: размер хитбокса врага и сдвиг картинки считаются по нему.
- **Walk / Attack / Hurt / Death animation** у `Create Enemy` — выбрать анимацию вручную (перекрывает Look).
- **Sprite offset X/Y**, **Sprite scale** — подправить положение картинки относительно хитбокса.

Отсутствующие состояния заменяются соседними (`windup` → `attack`, `idle` ↔ `walk`, оглушение → `hurt`).

## Объекты, сундуки, двери, предметы (0.16.0)

Встроенные картинки объектов можно заменить своими прямо в действии — через библиотеку *Map objects* PS Maker:

1. В PS Maker добавьте в *Map objects* свои картинки (например, куст, пень, горшок, сундук, дверь из Mana Seed) и для твёрдых настройте коробку коллизии, как для обычного объекта карты. На карту ставить их не нужно.
2. В действии выберите их из списка (первый вариант *Built-in* — встроенная картинка):
   - `Zelda: Create Object` → раздел *Look and size*: **Look (map object)** — обычный вид, **Look when used** — вид после использования: срубленный куст (пень), разбитый горшок (осколки), нажатая кнопка, включённый рычаг, открытый сундук;
   - `Zelda: Create Chest` → раздел *Look*: **Look: closed**, **Look: open**;
   - `Zelda: Create Door` → *Look and size*: **Look: closed**, **Look: open**;
   - `Zelda: Place Item` → раздел *Look*: **Look (map object)**.
3. Тело объекта (то, во что упирается игрок и по чему бьёт меч) — коробка коллизии объекта карты; без коробки — поля *Width*/*Height* (0 = 16). Если *Width*/*Height* заданы явно, они важнее коробки. Картинка рисуется в натуральную величину и стоит относительно тела так же, как объект карты в PS Maker.
4. Если задан *Look when used*, после разрушения на месте остаётся эта картинка (пень, осколки); без него разрушенный объект исчезает, как раньше.

Анимированный объект карты показывается первым кадром (Toolkit берёт текстуру `<id>_frames`, кадр 0). Поле *Sprite (image)* у `Create Object` по-прежнему принимает картинку из *Images* PS Maker; *Look* важнее него.

Список заполняется объектами открытого проекта, когда карта открыта в редакторе (Toolkit читает библиотеку раз в 300 мс). Если объект в библиотеке переименовали, действие продолжит работать: сохраняется id объекта.

## Как это работает

PS Maker 1.2.1 хранит данные проекта в `scene.sys.settings.data.story`, а каждую анимацию грузит текстурой всего листа под ключом `<id анимации>frames`; номер кадра = `строка × (ширина картинки / ширина кадра) + столбец` (см. ENGINE_AUDIT, раздел 11). Toolkit использует те же текстуры и ту же нумерацию. Объекты карты PS Maker грузит при загрузке всех карт текстурой под id объекта (анимированные — листом `<id>_frames`), поэтому они доступны на любой карте, даже если там не стоят.

## Проверка

- **F10** (или `Zelda: Debug` → Diagnostics): строка `PS Maker data: scene.data.story (…)` — данные проекта найдены; предупреждения покажут, если анимация или картинка листа не нашлись.
- Действия `Define Sprite Sheet` / `Define Animation` / `Preview Sprite Sheet` из старых версий больше не выполняются: PS Maker пропускает неизвестное действие плагина с предупреждением в консоли. Замените их выбором анимаций из PS Maker.

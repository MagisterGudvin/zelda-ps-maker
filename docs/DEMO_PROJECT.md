# Демонстрационный проект

Демо состоит из двух карт и описано один раз в [examples/harness/demo-maps.js](../examples/harness/demo-maps.js) — ровно теми действиями и параметрами, которые автор вводит в редакторе PS Maker. Его можно:

1. **запустить в браузере** через эмулятор хоста (`npm run harness`) — тот же бандл, что кладётся в PS Maker;
2. **воспроизвести в PS Maker** по инструкции ниже.

Все ассеты демо — процедурные оригинальные спрайты Toolkit (`src/host/textures.ts`) и простые прямоугольники; ничего из игр Nintendo.

## Запуск в браузере

```bash
npm install
npm run harness
# открыть http://127.0.0.1:8080/examples/harness/
```

Клавиши: стрелки/WASD, X меч, C предмет, Q/E выбор, Z поднять/открыть/бросить, I предметы, F9 хитбоксы; F5/F8/F6 — сохранить/загрузить/сбросить (в PS Maker эти действия ставятся на события меню или триггеры).

## Что проверяет демо (соответствие требованиям)

| # | Требование | Где в демо |
|---|---|---|
| 1 | Игрок, движение | хост (в PS Maker — штатное движение игрока) |
| 2 | Несколько противников | поле: 2 слизня, солдат, патрульный, стрелок, рыцарь-NPC; подземелье: волны и босс |
| 3 | Меч и попадания | любой враг; F9 показывает хитбокс удара |
| 4 | Бомба, разрушаемая стена, проход | сундук `bomb_chest` → треснувшая стена `secret_wall` → тайная комната с контейнером сердца |
| 5 | Бумеранг и переключатель | сундук `boomerang_chest` → кнопка `gate_switch` за ямами → правило открывает ворота `gate` |
| 6 | Щит и дальний враг | `spitter_1` у правого края; снаряды спереди блокируются |
| 7 | Сундук, ключ, запертая дверь | подземелье: `key_chest` → `key_door` |
| 8 | Блок и переключатель | подземелье: `block_1` → `plate_1` (latch) → `puzzle_door` |
| 9 | Инвентарь и ресурсы | HUD, панель (I), бомбы/стрелы/рупии, лук в `bow_chest` |
| 10 | Сохранение прогресса | переходы между картами сохраняют открытые сундуки/стены/ворота; F5/F8 |

## Воспроизведение в PS Maker

1. Скопируйте `dist/zelda-maker-toolkit.ps-maker.js` в `/plugins` проекта.
2. Создайте карту **field** 25×15 тайлов (16 px). Нарисуйте коллизии по прямоугольникам из `MAPS.field.walls`. Разместите NPC (любой персонаж) в точке (120, 184) — его выберете в действии `Zelda: Enemy From NPC`.
3. В **On-load events** карты добавьте по порядку действия из `MAPS.field.onLoad` (имя действия — первый элемент, параметры — второй). *Position* выберите на карте кнопкой рядом с полем (или введите указанные координаты). Маршрут патрульного и точки наград заданы маркерами (`Zelda: Place Marker`), а не числами.
4. Создайте карту **dungeon** и аналогично перенесите `MAPS.dungeon`.
5. Переходы: на правом краю поля (за воротами) поставьте триггер PS Maker *Transfer player* → dungeon (40, 200); на левом краю подземелья — обратно на поле (370, 120).
6. Враги арены добавлены действиями `Zelda: Add Wave Enemy` с выбором точки на карте. Триггер на входе в арену (x ≈ 216–232): группа событий с действием `Zelda: Start Waves` (Room ID `arena`).
7. Для проверки сохранений повесьте `Zelda: Save Progress` и `Zelda: Load Progress` на выбор в диалоге NPC или на триггеры.

> Если координаты параметра *Position* в вашей версии PS Maker приходят в тайлах, поставьте галочку *Positions in tiles* у `Zelda: Start Toolkit` (см. [ENGINE_AUDIT.md](ENGINE_AUDIT.md), U-2).

## Прохождение

1. Откройте сундук с бумерангом (вверху по центру) и с бомбами (внизу).
2. Положите бомбу у треснувшей стены слева сверху — внутри контейнер сердца.
3. Встаньте под кнопкой за ямами справа сверху, бросьте бумеранг вверх — ворота справа откроются.
4. Пройдите в подземелье, толкните блок вправо на плиту — откроется дверь наверх.
5. Возьмите ключ из сундука, откройте дверь в арену, победите две волны и стража-огра (3 фазы).
6. Вернитесь на поле — открытые сундуки и разрушенная стена остались.

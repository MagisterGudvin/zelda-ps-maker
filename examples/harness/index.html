Zelda Maker Toolkit — demo harness

This page emulates the PS Maker host (Phaser scene + Arcade player) to run the real plugin bundle. It is not PS Maker itself.

←↑→↓/WASD move · X sword (hold: spin) · C use item · Q/E switch item · Z lift / open / throw · V shield (hold mode) · I items · F9 hitboxes · F5 save · F8 load · F6 reset

Field: open chests (boomerang, bow, bombs), bomb the cracked wall (secret heart container), hit the switch behind the pits with the boomerang to open the gate. Dungeon: push the block onto the plate, take the key, open the locked door, survive the waves and beat the guardian.

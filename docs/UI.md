# Интерфейс: HUD, окно сообщений, главное меню, настройки, сохранения

С 0.17.0; сообщения диалогом PS Maker — с 0.18.0; HUD в окне игры редактора и масштаб «как карта» — с 0.19.0; иконки предметов и панель инвентаря из своих картинок — с 0.20.0. Что рисует PS Maker, а что Toolkit:

| Что | Кто рисует | Где настраивается |
|---|---|---|
| Главное меню | PS Maker (действие **Add UI**: тексты, картинки, кнопки) | титульная карта проекта |
| Настройки (громкость, полный экран, сохранить, выход) | PS Maker (меню опций, Escape) | Game UI → Options menu |
| Загрузка сохранений | PS Maker (меню загрузки) | Game UI → Load game menu |
| Диалоги NPC, выбор ответа | PS Maker (**Dialogue**, **Choices**) | Game UI → Dialogue layouts, Choice layouts |
| HUD: сердца, счётчики, рамка предмета, шкала магии | Toolkit, в пикселях карты | `Zelda: HUD Style`; части перетаскиваются мышью в окне игры на карте редактора |
| Свой HUD из компонентов (по желанию) | PS Maker (**Add UI**) по значениям Toolkit | `Zelda: HUD Variables` + Add UI (в конце страницы) |
| Таблички, «Вы получили…», подсказки | PS Maker (**Dialogue**), по выбору — окно Toolkit | `Zelda: Message Style` |

## HUD Toolkit из своих картинок — `Zelda: HUD Style`

1. Добавьте картинки в библиотеку **Images** PS Maker (например, из набора Mana Seed UI). Каждая картинка — отдельный файл; цифры — одна картинка с десятью цифрами `0123456789` в ряд, одинаковой ширины.
2. Поставьте `Zelda: HUD Style` в «Map start» после `Start Toolkit` (на каждой карте, как и `Start Toolkit`).
3. Поля (пустое поле — встроенная картинка):
   - **Toolkit HUD parts** — какие части рисует сам Toolkit: сердца, счётчики, рамка предмета, шкала магии (остальное — на Add UI). Фон полосы рисуется, пока видна хоть одна часть.
   - *Hearts*: **Heart: full / half / empty**, **LIFE label**. Размер полного сердца задаёт размер всех сердец.
   - *Counters*: значки **rupees, bombs, arrows, keys**, **Digits 0-9**.
   - *Item and magic*: **Item box** (рамка предмета; иконка предмета вписывается внутрь), **Magic meter: frame / fill**. Заливка рисуется поверх рамки и срезается сверху по мере траты магии.
   - *Bar and text*: **Bar background** — фон всей полосы, растягивается; его край шириной **Bar border (px)** не растягивается (9-slice). **Font** — шрифт проекта (Game UI → Fonts). **Text color**. **Scale** — размер пикселя HUD на экране; **0** (по умолчанию) — как у карты: один пиксель картинки HUD равен одному пикселю карты (при масштабе карты 4 — четыре пикселя экрана).
   - *Item icons*: **Icon: sword, shield, power glove, bomb item, boomerang, bow, hookshot, fire rod, healing spell** — свои иконки встроенных предметов в рамке предмета и в панели инвентаря (вписываются в клетку 16×16 пикселей HUD). У предметов из `Zelda: Define Item` иконка задаётся там же, в поле **Icon**.
   - *Inventory panel*: **Inventory panel** — фон панели предметов (клавиша I), 9-slice; край шириной **Panel border (px)** не растягивается, содержимое отступает от него. **Inventory cursor** — рамка выбранного предмета, 20×20 пикселей HUD, рисуется под иконкой (середину рамки можно оставить прозрачной).
   - *Positions*: **Hearts X / Y**, **Counters X / Y**, **Item box X / Y**, **Magic meter X / Y** — левый верхний угол части в пикселях HUD (при Scale 0 — в пикселях карты) от угла экрана; −1 — на своём месте в полосе. Удобнее не вводить числа, а перетащить часть мышью (ниже).

Раскладка берёт размеры картинок, поэтому большие сердца или значки не налезают друг на друга. Если полоса не помещается в ширину, сердца переносятся под счётчики. Когда хоть одна часть сдвинута, вместо полосы у каждой части свой фон (та же картинка **Bar background** с отступом 3 пикселя вокруг части). Чтобы фона не было, выберите в **Bar background** прозрачную картинку.

## HUD на карте в редакторе

На карте, где есть `Zelda: Start Toolkit`, редактор показывает жёлтую пунктирную рамку **Game window · Zelda HUD** — экран игры в начале (размер окна игры из Game settings, делённый на масштаб карты, с центром в точке старта игрока из **Move player**). В рамке HUD нарисован так же, как в игре: те же картинки, те же пиксели, что у карты.

Если на карте есть `Zelda: HUD Style`, части HUD (сердца, счётчики, рамка предмета, шкала магии) можно перетащить мышью. Когда кнопку отпускают, Toolkit открывает настройки `Zelda: HUD Style` и вписывает **X / Y** части, как если бы их ввели руками; PS Maker сохраняет их вместе с проектом. Отменить сдвиг — вписать −1 в оба поля. Без `HUD Style` рамка только показывает HUD (подпись подсказывает, что добавить).

HUD рисуется поверх игры, поэтому в игре его место не зависит от камеры: рамка в редакторе показывает, что закроет HUD в первом кадре.

## Шрифты

**Загрузка.** PS Maker загружает шрифт проекта только тогда, когда впервые показывает свой текст: меню, диалог или текст Add UI. Если тест запущен прямо с игровой карты, этого может не случиться. С 0.18.0 Toolkit сам загружает выбранный шрифт из папки ассетов проекта под тем же именем, что использует PS Maker. Пока шрифт грузится, текст рисуется запасным шрифтом без засечек и перерисовывается после загрузки.

**Русский текст и шрифт.** PixelOperator — шрифт нового проекта PS Maker — **без кириллицы**. Русские буквы в нём браузер берёт из другого шрифта (обычно с засечками), и надписи выглядят «не тем шрифтом»: «Получено: Бумеранг!», «- ЖИЗНЬ -», таблички на русском. Тексты Toolkit по-русски, когда язык Toolkit — *auto* и браузер или система русские. Добавьте в Game UI → Fonts пиксельный шрифт с кириллицей и выберите его в макете диалога (Dialogue layouts → стиль текста), в стилях кнопок и в `Zelda: HUD Style` → **Font**. В демо так сделано со шрифтом Pixelify Sans (SIL Open Font License 1.1).

## Сообщения Toolkit — `Zelda: Message Style`

Без этого действия сообщения Toolkit — короткие заметки над игрой, как раньше. С ним выбранные сообщения показываются в окне:

- **Show with** → **PS Maker Dialogue** (по умолчанию): сообщение — настоящий диалог PS Maker. Работает всё, что настраивается в Game UI → Dialogue layouts: фон, шрифт, имя, портрет, звук печати, анимации открытия, скорость. Клавиши — как у диалога PS Maker. Двоеточия, `@`, `*`, `_` и `{}` в тексте табличек экранируются, текст показывается как написан; пустая строка — новая страница.
- **Show with** → **Toolkit box**: Toolkit рисует окно сам, повторяя макет (как в 0.17.0); поля ниже — для этого режима.

- **Dialogue layout** — макет из Game UI → Dialogue layouts (*Default layout* — макет проекта по умолчанию). Из макета берутся: размер окна, отступы, расстояние от края, фон, стиль текста, скорость печати, цвет курсора. Фон может быть цветом (с рамкой и скруглением) или картинкой: *9-slice* (углы рисуются шириной *Border width*, как в PS Maker), *Stretch*, *Fit*. *Fill* и *Tile* рисуются растяжением.
- **Messages in the box**: таблички и тексты объектов; полученные предметы (из сундуков, большие предметы); подсказки («Заперто», «Нужен ключ», «Слишком тяжело»); короткие заметки («Сохранено», рупии и прочие мелочи). По умолчанию — таблички и предметы.
- **Type letter by letter**, **Wait for the action key**, **Pause the game**, **Position** (снизу или сверху; HUD окно не перекрывает).

Клавиша действия (Z) сначала показывает текст целиком, потом закрывает окно; следующее сообщение из очереди открывается сразу. Пока окно открыто, враги и игрок ждут.

`Zelda: Show Message` → **In a dialogue box** — показать свой текст в этом окне.

Разговоры с NPC делайте штатным **Dialogue** PS Maker: имя, портреты, выбор ответа, звуки — это всё у него есть. Пока открыт диалог PS Maker, Toolkit стоит на паузе (`combat.pauseDuringDialogue`).

## Главное меню

Титульного экрана в PS Maker нет: игра начинается со стартовой карты. Сделайте её меню:

1. Карта «Title» — стартовая (Player → Starting map).
2. «Map setup»: **Set player visibility** → Hide, **Toggle player movement** → Disable.
3. «Map start»: **Add UI** — текст с названием и кнопки. Событие каждой кнопки:
   - «Новая игра» → **Change map** на первую игровую карту;
   - «Продолжить» → **Open load game menu**;
   - «Настройки» → **Open game options menu** (без кнопки сохранения);
   - «Выход» → **Exit game**.
4. Не ставьте на титульную карту действия `Zelda:` — тогда Toolkit (и его HUD) на ней не запускается.

Стиль кнопок — Game UI → Button styles (фон-картинка 9-slice, шрифт, цвет).

## Настройки

Меню опций PS Maker (Escape) ставит игру на паузу; Toolkit стоит вместе с ней. Клавиши, нажатые в меню, после закрытия не срабатывают (меч не взмахнёт). Звуки Toolkit (`Zelda: Set Sound`) следуют ползунку **Sound Volume**, как звуки самого PS Maker.

## Сохранения PS Maker и прогресс Toolkit

PS Maker сохраняет позицию, переменные и состояние карт, а прогресс Toolkit (открытые сундуки, предметы, сердца, ключи) — нет. Свяжите их:

1. Создайте **текстовую** глобальную переменную, например «Zelda progress».
2. `Zelda: Start Toolkit` → **Progress variable** — выберите её (на каждой карте).

Toolkit держит в переменной свой прогресс. Когда PS Maker загружает сохранение и меняет переменную, Toolkit восстанавливает прогресс из неё. Когда переменная снова пустая (новая игра), Toolkit начинает сначала.

**Загрузка.** Карта, восстановленная из сохранения, не выполняет «Map setup» / «Map start» заново (так устроен PS Maker 1.2.1). Toolkit замечает такую карту и сам выполняет её действия `Zelda:`, которые строят карту (Start Toolkit, объекты, враги, правила, стили), без разовых эффектов вроде Give Item.

Сохранения Toolkit в localStorage (F5 / F8, `Save Progress` / `Load Progress`) по-прежнему работают отдельно.

## Дополнительно: свой HUD на Add UI — `Zelda: HUD Variables`

Обычно достаточно HUD Toolkit (выше). Если нужен HUD из компонентов PS Maker, Toolkit может держать свои значения в переменных проекта.

HUD можно собрать так же, как любой интерфейс PS Maker: действием **Add UI** — тексты, картинки, прямоугольники с фоном, где угодно и любого размера. Toolkit только держит значения в переменных проекта, а свойства компонентов Add UI берут их из переменных или выражений (`@{переменная}`, операции `+ − * /`, скобки).

1. Создайте числовые переменные (и текстовую для имени предмета) — например «HUD full», «HUD half», «HUD max», «HUD rupees».
2. `Zelda: HUD Variables` после `Start Toolkit` (на каждой карте) — выберите переменные:
   - **Full hearts** — целые сердца; **Half heart** — 1, пока есть половинка, иначе 0; **Heart containers** — все сердца;
   - **Magic %** (0–100); **Rupees**, **Bombs**, **Arrows**, **Small keys**;
   - **Selected item name** (текстовая), **Selected item ammo**.
   Любое другое значение — `Zelda: Show Stat In Variable`: здоровье в единицах, «предмет выбран» / «предмет есть» (1 или 0) для любого предмета и т. д.
3. `Zelda: HUD Style` → **Toolkit HUD parts** — снимите галочки с частей, которые рисует Add UI (например, оставьте только *Item box* и *Magic meter*).
4. **Add UI** в «Map start» после действий Toolkit. Примеры:
   - ряд сердец: прямоугольник с фоном-картинкой *Tile* (картинка сердца), привязка размера *Top left*, ширина — выражение `@{HUD full} * 36`, высота 32. Под ним такой же ряд пустых сердец шириной `@{HUD max} * 36`;
   - половинка: прямоугольник с картинкой половины сердца, X — `<x ряда> + @{HUD full} * 36`, прозрачность фона — `@{HUD half} * 100`;
   - счётчик: картинка-значок и текст, значение которого — переменная `HUD rupees`;
   - шкала магии: прямоугольник, высота — `@{HUD magic} * 0.6`;
   - значок выбранного предмета: картинка лука с прозрачностью `@{bow selected} * 100` (переменная от `Show Stat In Variable` → *Item is selected*, предмет *Bow*), и так для каждого предмета.

PS Maker рисует картинки интерфейса в логических пикселях игры (обычно 1280×720), а не в пикселях карты. При масштабе карты 4 картинку размером 9×8 нужно нарисовать вчетверо крупнее (36×32), чтобы она совпала по размеру с пикселями игры.

Выражения PS Maker умеют только `+ − * /`, без сравнений и округления. Поэтому Toolkit отдаёт готовые целые числа и признаки 1/0.

Иконку выбранного предмета Add UI менять по переменной не умеет (картинка компонента постоянная). Её рисует рамка предмета Toolkit или набор картинок с прозрачностью по признакам *Item is selected*.

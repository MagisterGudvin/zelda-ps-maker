## Ручные сценарии в PS Maker

Выполнить после установки `dist/zelda-maker-toolkit.ps-maker.js` в `/plugins`. Результат каждого шага сверить с ожидаемым; при расхождении приложить вывод консоли браузера (`[ZeldaMakerToolkit]`).

| ID | Сценарий | Ожидаемо |
|---|---|---|
| M-01 | Открыть проект, добавить событие: в списке есть действия `Zelda: …` | 40 действий. Проверить виджеты: у *Position* и полей «… at» — кнопка выбора на карте; у *Patrol route* и *Switches in order* — путь; у *Room area* — область; у *Template*, *Type*, *Lock*, *Item*, *Group* — списки; у *Reacts to* — множественный выбор; переменные, анимации, клавиши — штатные пикеры. Если какой-то виджет не появился (пустое или текстовое поле) — прислать скриншот формы |
| M-02 | Map start: `Zelda: Start Toolkit`, запустить playtest | В консоли нет ошибок; вверху HUD с сердцами |
| M-03 | `Zelda: Create Enemy` с Position | Слизень появляется в выбранной точке. Если смещён в ~16 раз — Position в тайлах: галочка *Positions in tiles* у `Start Toolkit` |
| M-04 | Подойти к врагу, нажать X | Меч виден в направлении взгляда, у врага −2 HP (F9: красный хитбокс), враг отлетает; во время удара игрок не двигается |
| M-05 | Дать врагу коснуться игрока | −1 HP, игрок отлетает и мигает ~1 с, повторного урона нет |
| M-06 | Стены карты | Враги и снаряды не проходят сквозь коллизии карты. Если проходят — в консоли предупреждение `No Arcade static bodies…`: коллизии PS Maker устроены иначе |
| M-23 | Start Toolkit + Create Enemy + Show Message в событиях начала карты, F10 | Враг на месте, сообщение показано; в `actions run:` — все три действия (PS Maker дошёл до конца события) |
| M-22 | `Create Enemy` с выбранным в списке *Look* персонажем Slime, F10 | Строка `PS Maker data:` показывает, где найдены данные проекта; слизень ходит анимациями Slime Run/Idle. Если «not reachable» — прислать скриншот панели и (по возможности) экспорт игры |

## Как писать новые тесты

- Логика: `tests/helpers/fakeHost.ts` → `createRig(config)` даёт `Toolkit`, `FakeHost` (игрок-бокс, стены, ввод) и `Session`; `rig.host.walk(dx, dy)` имитирует движение PS Maker, `rig.host.input.tap("sword")` — нажатие, `rig.run(ms)` — время.
- Phaser-адаптер: `tests/helpers/fakePhaser.ts` (эмиттеры со счётчиками) или интеграционный тест.

# Zelda Maker Toolkit для PS Maker

Плагин для [PS Maker (Pixel Stories)](https://pixelstories.io/), который добавляет боевую систему в реальном времени и инструменты 2D action-adventure игр в духе классических top-down приключений (ориентир — *A Link to the Past*): меч с заряженным круговым ударом, щит, бомбы, бумеранг, лук, магию, врагов с ИИ, интерактивный мир, головоломки, подземелья, HUD и сохранения.

Всё настраивается через **штатный редактор событий PS Maker**, как в конструкторе: 37 действий `Zelda: …` с выпадающими списками, галочками, числами с пояснениями и штатными кнопками выбора на карте (точка, путь, область), выбором переменных, анимаций и клавиш. Текст вводится только там, где это содержание: надписи на табличках, сообщения, названия предметов. Формы разбиты на сворачиваемые разделы, неприменимые поля скрываются, в списке событий у каждого действия — краткое описание, на карте редактора видно, что создадут действия (враги, сундуки, двери, объекты, арены, их коллизии), двойной щелчок по картинке открывает её действие, поиск по английским ключевым словам («enemy», «chest», «door»; русские слова поиск редактора PS Maker не поддерживает).

> Статус: **0.22.0, MVP** (сверено с исходным кодом рантайма PS Maker 1.2.1). Логика покрыта 256 юнит-тестами и 23 интеграционными проверками в настоящем Phaser 3.90 (headless Chromium) через эмулятор хоста PS Maker; демо-проект проходится в настоящем рантайме PS Maker 1.2.1 (18 проверок `scripts/runtime-check.mjs`: главное меню, HUD в пикселях карты, панель инвентаря на своей картинке, сообщения диалогом PS Maker, шрифт с кириллицей, меню опций, сохранение и загрузка через меню PS Maker); HUD на карте редактора и его перетаскивание проверены в сборке редактора PS Maker 1.2.1 в Chromium. В PS Maker 1.2.1 подтверждено пользователем (0.8.0): плагин загружается; враг появляется, преследует игрока и наносит урон, игрок наносит урон врагу, при касании враг отскакивает, а не проходит сквозь игрока; разделы форм сворачиваются, неприменимые поля скрываются, краткие описания видны в списке событий, поиск работает по английским словам; (0.16.0) списки *Look* заполняются объектами карты проекта, выбранные картинки видны на карте редактора, в игре пень остаётся после удара, сундук со своей картинкой открывается. Сундуки, двери, блок и плита, волны, страж и возврат на карту проверены скриптом в рантайме PS Maker; руками в редакторе — ещё нет. Что нужно проверить вручную — см. [docs/TESTING.md](docs/TESTING.md).

## Установка

1. Скопируйте `dist/zelda-maker-toolkit.ps-maker.js` в папку `/plugins` вашего проекта PS Maker (плагины — бета-функция PS Maker; файл загружается автоматически).
2. В событиях начала каждой карты (Map start) добавьте первым действием **`Zelda: Start Toolkit`**. Карта узнаётся по её id в PS Maker — по нему запоминаются сундуки, двери и переключатели.
3. Добавьте врагов и объекты действиями `Zelda: Create Enemy`, `Zelda: Create Object`, `Zelda: Create Chest`, `Zelda: Create Door`.

Сборка из исходников:

```bash
npm install
npm run build          # официальный @ps-maker/plugin-cli → dist/zelda-maker-toolkit.ps-maker.js
npm run check          # typecheck + юнит-тесты + сборка + интеграционный тест в Chromium
npm run harness        # демо в браузере: http://127.0.0.1:8080/examples/harness/
node scripts/make-demo-project.mjs --from "<ваш проект>"   # демо-проект PS Maker со встроенными ассетами
```

Демо-проект (поле и подземелье на встроенном наборе «Tiles 'N Such Assets») создаётся рядом с любым вашим проектом, где этот набор добавлен, — см. [docs/DEMO_PROJECT.md](docs/DEMO_PROJECT.md).

Нужен Node.js ≥ 22.18 (тесты запускаются встроенным `node --test` с удалением типов TypeScript).

## Быстрый старт (события «Map start» карты)

| # | Действие | Поля |
|---|---|---|
| 1 | `Zelda: Start Toolkit` | Сложность — список, сердца и урон меча — числа, остальное — галочки |
| 2 | `Zelda: Create Enemy` | Template = `slime`, Position = точка на карте |
| 3 | `Zelda: Create Chest` | Item = *Boomerang*, Position = точка на карте |
| 4 | `Zelda: Create Object` | Type = *Button*, Position = точка на карте |
| 5 | `Zelda: Create Door` | Lock = *Switch / rule*, Position = точка на карте |
| 6 | `Zelda: Add Rule` | When object at = кнопка (клик по карте), Open door at = дверь (клик по карте) |

Имена и id вводить не нужно: объекты выбираются кликом по карте, группы врагов — Group 1–9, свои типы врагов и предметов — слоты Custom 1–N. Состояние Toolkit видно событиям PS Maker через переменные проекта (*Turn on variable*, `Zelda: Show Stat In Variable`). Редкие настройки — из JS API (`ZeldaMakerToolkit.configure`, `addRule`).

*Position* выбирается на карте кнопкой, как у встроенных событий (тип поля `map-position`, найден в коде PS Maker 1.2.1). Варианты (шаблон врага, тип объекта, замок двери, сложность…) — выпадающими списками. Если в вашей версии редактора кнопки нет, координаты можно снять в игре: **F9** и клик по карте — «X: … Y: …» копируется в буфер обмена. Маршрут патруля и порядок переключателей — путь по карте, комната с волнами — область на карте.

Управление по умолчанию (меняется действием `Zelda: Set Controls` — штатный выбор клавиш PS Maker): стрелки/WASD — движение PS Maker; **X** — меч (удерживать — круговой удар); **C** и **B** — две кнопки предметов (I: выбрать предмет и нажать C или B, чтобы поставить его на эту кнопку); **Q/E** — смена предмета на C; **Z** — поднять/бросить/открыть (та же клавиша, что взаимодействие в PS Maker); **V** — держать щит (сначала его нужно найти; с поднятым щитом игрок идёт медленнее, а враги, наткнувшиеся на щит, отлетают); **I** — инвентарь; **Escape** — меню паузы, если оно сделано в дизайнере (иначе меню опций PS Maker); геймпад работает сразу (Xbox, PlayStation, Nintendo, Steam Deck: A — меч, B — действие, X/Y — предметы, RB — щит, стик — движение), мышь можно назначить на действия, а игрок меняет клавиши сам на экране управления (меню паузы → *Controls* в демо); **F9** — хитбоксы (клик по карте — координаты); **F10** — диагностика.

## Возможности

- **Бой**: фазы удара (подготовка/удар/восстановление), хитбокс только в активной фазе, не более N попаданий по цели за удар, отбрасывание, заряд и круговой удар, «тычок» при заряде, неуязвимость с миганием, смерть и возрождение.
- **Предметы**: бомбы (фитиль, радиус, цепная реакция, разрушение), бумеранг (оглушение, возврат, переключатели, сбор предметов), лук и стрелы, щит и Зеркальный щит (держатся клавишей, блокируют и отталкивают; зеркальный отражает выстрелы), Сапоги-скороходы (рывок, с мечом — атака), Перо Рока (прыжок через ямы), крюк-кошка (через ямы к столбам и сундукам), лопата (закопанные клады), подбор и бросок бомб, волшебный порошок, бомбо-стрелы (лук и бомбы на двух кнопках вместе), две кнопки предметов, как в ремейке Link's Awakening, огненный жезл и лечебное заклинание (магия). Новые предметы — полями `Zelda: Define Item` или через JS API.
- **Враги**: 6 шаблонов на 5 поведениях — ближний бой, стрелок, защищающийся рыцарь, патрульный, многофазный мини-босс; сопротивления по типам урона, выпадение предметов, «усыновление» NPC из редактора.
- **Мир**: кусты, трава, горшки и камни (поднять и бросить), разрушаемые блоки и стены, рычаги, кнопки, нажимные плиты, толкаемые блоки, сундуки, двери с ключами, скрытые проходы, факелы, шипы, ямы, таблички.
- **Головоломки и подземелья**: правила «условие → действия» (24 условия, 33 действия, расширяемо), последовательности переключателей, комнаты с волнами врагов, ключи и большой ключ на подземелье, боссы, завершение подземелья.
- **HUD в классическом стиле**: шкала магии, рамка предмета, пиксельные счётчики, «— LIFE —» и сердца по 10 в ряд, сообщения в рамках, панель предметов; раскладка проверена тестами на отсутствие наложений на 6 разрешениях; отдельная Phaser-сцена; русский и английский.
- **Интерфейс**: дизайнер HUD и экранов меню прямо на карте редактора (`Zelda: UI Layout`), как в графическом редакторе: создание по правому щелчку, выделение нескольких, прилипание к краям и сетке, выравнивание, группы, блокировка, копирование, поворот, прозрачность, эффекты, отмена. Элементы: картинки, тексты со значениями и обводкой, полосы-фигуры (пилюля, круг, звезда, сердце…), сердца, счётчики, рамка предмета, иконки из листа, слоты быстрого доступа 1–9, мини-карта, кнопки, сетка инвентаря; условия показа по переменной, предмету или сравнению значения; экраны с ролями — меню паузы (Escape), окно сообщений Toolkit с печатью текста, окно реплик NPC (`Zelda: Dialogue`: имя, портрет), уведомления, инвентарь (I), титульный экран — и свои экраны (магазин) с кнопками, которые запускают события PS Maker, открывают другие экраны или меняют переменные, управляются стрелками и мышью, со звуками; слои над HUD (полоса босса), под которыми игра идёт; значения Toolkit в переменных проекта для своего UI (`Zelda: Show Stat In Variable`); настройки и сохранения — меню PS Maker — [docs/UI.md](docs/UI.md).
- **Анимации и картинки из PS Maker**: атаки игрока и враги берут анимации и коллизию персонажей прямо из библиотеки PS Maker (например, Mana Seed), объекты, сундуки, двери и предметы — картинки и коллизию объектов карты (*Look*) — [docs/SPRITES.md](docs/SPRITES.md).
- **Звук и NPC PS Maker**: звуки моментов боя из аудио-ассетов (`Zelda: Set Sound`); враги и снаряды не проходят сквозь NPC (коллизии NPC появились в PS Maker 1.1).
- **Диагностика**: F10 или `Zelda: Debug` — панель с позициями, глубинами, ближайшими объектами и последними предупреждениями прямо на экране.
- **Сохранения**: прогресс Toolkit хранится в текстовой переменной проекта и попадает в сохранения PS Maker (меню опций и загрузки); версионированный формат, миграции, санитизация старых/повреждённых данных.
- **Отладка**: оверлей хитбоксов и состояний (F9), логирование с уровнями; ошибки самого PS Maker тоже видны в панели диагностики.

## Главные ограничения

API плагинов PS Maker (`@ps-maker/plugin-api@0.0.3`) даёт только пользовательские действия и контекст `{ game, scene, player }`. Поэтому:

- ветвления событий PS Maker по состоянию Toolkit невозможны — используйте правила Toolkit (`Zelda: Add Rule`, `Zelda: Run Actions`);
- встроенные переменные, инвентарь, диалоги и сохранения PS Maker плагину недоступны — Toolkit ведёт собственные;
- движением игрока управляет PS Maker; отбрасывание и блокировка на время удара делаются коррекцией позиции спрайта после шага физики;
- форматы параметров `position`, `npc`, `image` не задокументированы — плагин принимает все правдоподобные варианты и пишет в лог, если не распознал.

Подробно — в [docs/ENGINE_AUDIT.md](docs/ENGINE_AUDIT.md).

## Авторские права

Код написан с нуля. Все временные ассеты (спрайты, иконки, сердца) нарисованы процедурно в рантайме (`src/host/textures.ts`), ресурсы Nintendo не используются, ROM не нужен. Zelda3 использовался только как технический референс поведения. См. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

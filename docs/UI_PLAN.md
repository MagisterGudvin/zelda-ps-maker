# План: интерфейс (HUD из ассетов, главное меню, настройки, диалоги) — 0.17.0

Запрос пользователя: кастомизация HUD своими ассетами, главное меню, настройки, диалоговое окно; всё — в демо. Делается по шагам, после каждого — проверки и коммит.

## Что уже есть в PS Maker 1.2.1 (исходники рантайма, ENGINE_AUDIT, раздел 17)

| Нужно | В PS Maker | Решение |
|---|---|---|
| Главное меню | Титульного экрана нет; первая карта — `player.startingMap`. Есть действие **Add UI** (тексты, картинки, прямоугольники, **кнопки**: кнопка запускает событие проекта по `storyEventId`), **Open load game menu**, **Open game options menu**, **Exit game**, **Change map** | Меню собирается штатными средствами на титульной карте; Toolkit не рисует своё меню |
| Настройки | Меню опций (по Escape): громкость музыки и звуков, полный экран, сохранить, выход; стиль в `gameUI.optionsMenu` | Используем его. Звуки Toolkit пока **не** следуют ползунку *Sound Volume* — исправить |
| Сохранение / «Продолжить» | Сохранение PS Maker: позиция, переменные, снимки карт. После загрузки «Map start» карт со снимком **не выполняется заново** (`MapStartup`) — значит, `Start Toolkit` не запустится, и прогресс Toolkit (сундуки, предметы) в сохранение не попадает | Toolkit сам перезапускается на восстановленной карте и хранит прогресс в текстовой переменной проекта (переменные PS Maker сохраняет) |
| Диалоговое окно | Действие **Dialogue** со стилями `gameUI.dialogLayouts`: фон — цвет или **картинка с 9-slice**, шрифт проекта, портреты, печать по буквам | Диалоги NPC — штатные. Сообщения Toolkit (таблички, «Вы получили…», «Заперто») — в стиле выбранного макета диалога PS Maker: тот же фон, шрифт, отступы; режим окна с печатью по буквам и ожиданием клавиши |
| HUD | У PS Maker HUD нет; HUD Toolkit рисуется встроенными спрайтами | Действие `Zelda: HUD Style`: картинки из библиотеки *Images* для сердец, счётчиков, цифр, рамок, фона |

## Шаги

1. **Toolkit в сохранениях PS Maker.**
   - На карте, восстановленной из сохранения (снимок без сохранённого запуска), Toolkit выполняет свои действия из «Map setup» / «Map start» сам.
   - `Start Toolkit` → поле *Progress variable* (текстовая переменная): прогресс Toolkit всегда записан в ней, а когда PS Maker при загрузке меняет её значение, Toolkit восстанавливает прогресс из неё.
   - Проверки: юнит-тесты; рантайм — сохранить через меню опций, перезапустить, загрузить через меню загрузки: Toolkit работает, открытый сундук открыт, рупии на месте.
2. **Настройки.** Звуки Toolkit умножаются на громкость звуков PS Maker (`game.audioSettings.scaleSoundVolume`); нажатия, сделанные пока открыто меню (игра на паузе), не срабатывают после закрытия. Проверки: юнит-тесты; рантайм — Escape открывает меню, игра стоит, громкость применяется.
3. **HUD из ассетов** — `Zelda: HUD Style`: сердца (полное, половина, пустое), значки счётчиков, лента цифр 0–9, рамка предмета, шкала магии (рамка и заливка), фон полосы (9-slice с отступами), цвет и шрифт подписи, показать/скрыть фон. Пустое поле — встроенная картинка. Проверки: юнит-тесты раскладки (ничего не перекрывается при своих размерах), интеграция в Phaser, рантайм — текстуры HUD из проекта.
4. **Диалоговое окно Toolkit** — `Zelda: Message Style`: макет диалога PS Maker (список из проекта), режим (короткое сообщение / окно с печатью по буквам и ожиданием клавиши взаимодействия), какие сообщения в окне (таблички, предметы из сундуков, подсказки). Фон «цвет» и «картинка 9-slice», шрифт проекта, размеры в логических пикселях игры. Проверки: юнит-тесты (печать, ожидание клавиши, пауза), интеграция, рантайм.
5. **Ассеты UI для демо** — свои пиксельные картинки (рамки, кнопка, сердца, значки, цифры) в палитре набора, PNG пишет скрипт без зависимостей. Проверки: тест генератора.
6. **Демо.**
   - Титульная карта: название, кнопки «Новая игра» (Reset Progress → Change map), «Продолжить» (Open load game menu), «Настройки» (Open game options menu), «Выход» (Exit game).
   - Стили кнопок, меню опций и загрузки, макет диалога — на картинках из шага 5.
   - Старик у входа говорит штатным Dialogue.
   - Табличка и сундуки — окном Toolkit в том же стиле.
   - HUD Style на своих картинках.
   - Проверки: тесты генератора; рантайм — титульный экран → новая игра → поле; HUD; табличка; Escape → сохранить → перезапуск → «Продолжить» → загрузка.
7. **Документация и выпуск 0.17.0**: README, CHANGELOG, ENGINE_AUDIT (раздел 17), TESTING, DEMO_PROJECT, новые разделы в docs (HUD, сообщения, сохранения); `npm run check`, рантайм-проверка, коммит.

## Ограничения

- Ядро PS Maker не меняется; используются только данные проекта, `game.variables`, `game.audioSettings`, поля сцены карты (см. ENGINE_AUDIT).
- Шрифт проекта PS Maker загружает при первом показе своего окна; до этого текст Toolkit рисуется запасным шрифтом макета и перерисовывается, когда шрифт загрузится.
- Ручная проверка в редакторе — сценарии в TESTING.md.

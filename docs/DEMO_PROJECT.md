# Демонстрационный проект

Демо — главное меню и две карты (поле и подземелье), описанные один раз в [examples/harness/demo-maps.js](../examples/harness/demo-maps.js) теми действиями и параметрами, которые автор вводит в редакторе PS Maker. Его можно:

1. **создать как проект PS Maker** со встроенными ассетами набора «Tiles 'N Such Assets» — одной командой (ниже);
2. **запустить в браузере** через эмулятор хоста (`npm run harness`) — без PS Maker, с процедурными спрайтами Toolkit.

Ничего из игр Nintendo: оформление — встроенный набор PS Maker, логика — действия Toolkit.

## Проект PS Maker одной командой

Нужен любой ваш проект, в который добавлен встроенный набор **Tiles 'N Such Assets** (террейны, объекты карты, персонажи) — например «Istina». Он только читается; рядом создаётся новый проект.

```bash
npm install
npm run build
node scripts/make-demo-project.mjs --from "Istina"
```

- `--from` — имя проекта в папке проектов PS Maker или путь к папке проекта. Без `--from` команда покажет список проектов.
- `--name` — имя нового проекта (по умолчанию `Zelda Toolkit Demo`); если такая папка уже есть, ничего не меняется.
- Папка проектов: Linux — `~/.local/share/PS Maker/projects` (или `$XDG_DATA_HOME/PS Maker/projects`), Windows — `%LOCALAPPDATA%\PS Maker\projects`, macOS — `~/Library/Application Support/PS Maker/projects`; другую можно указать `--root`.

Затем откройте PS Maker — проект «Zelda Toolkit Demo» в списке. Внутри:

| Что | Где в редакторе |
|---|---|
| Карта **Title** (стартовая): главное меню — название и кнопки *New game*, *Continue* (меню загрузки), *Settings* (меню опций), *Exit*; игрок спрятан | «Map setup» и «Map start» карты Title: *Add UI*, события кнопок |
| Свои картинки интерфейса (рамка окна, кнопка, полоса HUD, сердца, значки, цифры, рамка предмета, шкала магии) — нарисованы `scripts/ui-assets.mjs` | Библиотека *Images* («Zelda UI …») |
| Макет диалога «Zelda dialogue» (по умолчанию), стиль кнопок «Zelda button», меню опций, загрузки и выбора — на этих картинках | Game UI |
| HUD Toolkit на картинках демо, в пикселях карты (*Scale* 0); в редакторе — в жёлтой рамке *Game window* на карте, части перетаскиваются мышью | «Map start»: `Zelda: HUD Style` |
| Шрифт Pixelify Sans с кириллицей (SIL OFL 1.1, лицензия — `PixelifySans-OFL.txt` в папке проекта) в диалогах, кнопках, меню и HUD | Game UI → Fonts |
| Таблички и полученные предметы — диалогом PS Maker на макете «Zelda dialogue» | `Zelda: Message Style` → *PS Maker Dialogue* |
| Житель у старта (персонаж *New Female*) говорит штатным диалогом | «Map setup» поля; «Map start»: *Add event trigger* (взаимодействие) → *Dialogue* |
| Прогресс Toolkit в сохранениях PS Maker | переменная «Zelda progress»; `Start Toolkit` → *Progress variable* |
| Карты **Field** и **Dungeon**: трава, тропинка, забор, каменные стены; пол и стены подземелья; деревья, кусты, камни, бочки, ящики | Террейн-слои «Ground» и «Details», объекты карты |
| Коллизии стен | Слой коллизий карты |
| Старт игрока и стражник (персонаж *New Female*) | «Map setup» поля |
| Все действия `Zelda:` | «Map start» каждой карты |
| Переходы между картами | «Map start»: *Add event trigger* (касание) → *Change map* |
| Облик врагов: слизни — *Slime*, патрульный — *Bone Slime*, стрелок — *Magma Slime*, солдат — *New Male*, страж арены — *Bull* | *Look* у `Create Enemy`; у волн и стража — типы `Define Enemy` (Custom enemy 1–4) |
| Удар и ранение игрока — листы *Sword Attack*, *Sword Hurt*, если они есть у игрока | `Zelda: Set Player Sprites` |

Всё можно менять в редакторе как обычный проект: двигать объекты, перерисовывать террейн, менять параметры действий.

## Что проверяет демо

| # | Требование | Где в демо |
|---|---|---|
| 1 | Игрок, движение | штатное движение игрока PS Maker |
| 2 | Несколько противников | поле: 2 слизня, солдат, патрульный, стрелок, рыцарь из NPC; подземелье: две волны и страж |
| 3 | Меч и попадания | любой враг; F9 показывает хитбоксы |
| 4 | Бомба, разрушаемая стена, проход | сундук с бомбами внизу → треснувшая стена слева вверху → тайная комната с контейнером сердца |
| 5 | Бумеранг и переключатель | сундук с бумерангом → кнопка за ямами справа вверху → правило открывает ворота |
| 6 | Щит и дальний враг | стрелок справа внизу; снаряды спереди блокируются |
| 7 | Сундук, ключ, запертая дверь | подземелье: сундук с ключом → дверь в арену |
| 8 | Блок и переключатель | подземелье: блок → плита → дверь наверх |
| 9 | Инвентарь и ресурсы | HUD, панель (I), бомбы/стрелы/рупии, лук в сундуке |
| 10 | Сохранение прогресса | при возврате на карту открытые сундуки, стены и ворота остаются; Escape → *Save game*, затем в меню *Continue*; F5/F8 в браузерном демо |
| 11 | Главное меню, настройки | карта Title; Escape в игре — меню опций PS Maker (громкость действует и на звуки Toolkit) |
| 12 | HUD и окна в своих картинках | `HUD Style`, `Message Style`, Game UI; табличка у старта, житель |

## Прохождение

0. В главном меню нажмите *New game*. У старта прочитайте табличку (Z) и поговорите с жителем.
1. Откройте сундук с бумерангом (вверху по центру) и с бомбами (внизу).
2. Положите бомбу у треснувшей стены слева сверху — внутри контейнер сердца.
3. Встаньте под кнопкой за ямами справа сверху, бросьте бумеранг вверх — ворота справа откроются.
4. Пройдите в подземелье, толкните блок вправо на плиту — откроется проход наверх.
5. Возьмите ключ из сундука, откройте дверь в арену, победите две волны и стража (3 фазы) — откроется тайный сундук.
6. Вернитесь на поле — открытые сундуки и разрушенная стена остались, враги поля снова на месте.
7. Escape → *Save game*; перезапустите игру → *Continue* → сохранение: всё на месте.

Клавиши: стрелки — движение, X — меч (удержать — круговой удар), C — предмет, Q/E — выбор предмета, Z — поднять/открыть/бросить/читать/говорить, I — предметы, Escape — меню опций, F9 — хитбоксы, F10 — диагностика.

## Запуск в браузере (без PS Maker)

```bash
npm install
npm run harness
# открыть http://127.0.0.1:8080/examples/harness/
```

Эмулятор ведёт себя как PS Maker 1.2.1 в главном: каждая карта — своя сцена, при смене карты она засыпает и потом просыпается, «Map start» выполняется один раз. F5/F8/F6 — сохранить/загрузить/сбросить (в PS Maker эти действия ставятся на кнопки меню или триггеры).

## Проверка в настоящем рантайме PS Maker

`scripts/runtime-check.mjs` запускает созданный проект в рантайме PS Maker из **вашего** веб-экспорта (Export → HTML5, распакованный) и проходит демо: главное меню и *New game*, HUD на картинках проекта в пикселях карты, шрифт с кириллицей, табличка диалогом PS Maker, разговор с жителем, сундуки («Получено: Бумеранг!» — диалогом PS Maker в шрифте демо), меню опций и *Save game*, переход, блок и плита, ключ и дверь, волны и страж, возврат на поле, перезагрузка страницы, *Continue* и загрузка сохранения.

```bash
node scripts/runtime-check.mjs --export ~/istina-web --project "$HOME/.local/share/PS Maker/projects/Zelda Toolkit Demo" --chrome /usr/bin/chromium
```

Файлы экспорта не копируются в репозиторий: временная сборка и скриншоты — в `tests/runtime/.artifacts/`. Результат последнего запуска — в [TESTING.md](TESTING.md).

## Вручную

Если удобнее собрать демо самому: карты 25×15 тайлов (16 px), стены — прямоугольники `walls` (слой коллизий), действия — по порядку из `onLoad` в «Map start» (имя действия — первый элемент, параметры — второй), переходы — `triggers` (Add event trigger → Player touch → Change map). Точки и области выбирайте на карте кнопкой рядом с полем.

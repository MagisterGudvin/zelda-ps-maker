# Предметы, ресурсы и инвентарь

## Предметы и ресурсы

| ID | Тип | Использование |
|---|---|---|
| `sword` | экипировка | кнопка меча |
| `shield` | экипировка | держать V: блокирует спереди выстрелы, стрелы и врагов (отталкивает их); игрок идёт медленнее и смотрит, куда смотрел |
| `mirror_shield` | экипировка | как щит, и отражает выстрелы и магию обратно в стрелка (`shield.reflects`) |
| `glove` | экипировка | подъём камней (сам, клавишей действия) |
| `boots` | быстрый предмет | Pegasus Boots: держать кнопку предмета — разбег на месте, затем рывок до стены или пока кнопка нажата; с мечом рывок бьёт врагов, кусты и траву впереди; стена — отскок назад |
| `feather` | быстрый предмет | Roc's Feather: прыжок — ямы, шипы и наземные враги в воздухе не действуют; прыжок на бегу с сапогами — длинный |
| `hookshot` | быстрый предмет | крюк-кошка: крюк летит вперёд (`items.hookshot.range`); враг — урон и оглушение, выпавший предмет — приносит игроку, столб (`hook_post`), сундук, блок, камень, горшок, табличка, факел, рычаг (`items.hookshot.grabs`) — подтягивает игрока к нему, над ямами; стена — возвращается |
| `shovel` | быстрый предмет | лопата: копает перед игроком — закопанный клад (`Create Chest` с *Buried*), иначе с шансом дроп (`items.shovel.drops`); стены и твёрдые объекты не копаются; ямка видна несколько секунд |
| `magic_powder` | быстрый предмет, ресурс `powder` | волшебный порошок: облако перед игроком — урон магией и оглушение врагов, огонь для объектов (факелы зажигаются, кусты сгорают); при получении — 10 порошка, `powder` — пополнение |
| `bomb_arrow` | комбинация | бомбо-стрела: лук и бомбы на двух кнопках предметов, нажатые вместе (в пределах `items.bombArrow.comboMs`); летит как стрела, взрывается как бомба; тратит стрелу и бомбу |
| `bomb` | быстрый предмет, ресурс `bombs` | положить бомбу (выдаётся автоматически вместе с бомбами) |
| `boomerang` | быстрый предмет | оглушает, возвращается, нажимает кнопки, приносит предметы |
| `bow` | быстрый предмет, ресурс `arrows` | стрела |
| `fire_rod` | быстрый предмет, ресурс `magic` | огненный шар, зажигает факелы |
| `healing_spell` | быстрый предмет, ресурс `magic` | лечение (не тратит магию при полном здоровье) |
| `bombs`, `arrows`, `rupees` | ресурсы | ёмкость `inventory.capacities` |
| `magic` | ресурс | банка магии |
| `heart` | подбор | +1 сердце здоровья |
| `heart_container` | подбор | +1 сердце максимума и полное лечение |
| `key`, `big_key`, `map`, `compass` | подземелье | считаются для текущего подземелья |

Выдать — `Zelda: Give Item` (сундук, NPC, магазин). Потратить — `Zelda: Spend Resource`. Забрать — `Zelda: Remove Item`. Поставить на кнопку предмета — `Zelda: Equip Item` (*Item button*: первая C или вторая B). Временно запретить (например, меч в деревне) — `Zelda: Set Ability` (`sword`, `false`).

Ресурс списывается только при успешном использовании; при нехватке — сообщение «Недостаточно: …» и событие `zelda:item:failed` с `reason: "noResource"`.

## Две кнопки предметов и инвентарь (с 0.29.0)

Как в ремейке *Link's Awakening*: у предметов две кнопки, и на каждую можно поставить любой быстрый предмет.

- **C** — первая кнопка предмета, **Q/E** — переключить её предмет; порядок — `inventory.order`, затем порядок получения. Предмет второй кнопки при переключении пропускается.
- **B** — вторая кнопка предмета (`controls.useItem2`).
- **I** — экран инвентаря (роль *Inventory* в дизайнере): стрелки выбирают предмет, **C** или **Z** ставят его на первую кнопку, **B** — на вторую. Предмет, который уже стоит на другой кнопке, меняется с ней местами. Без экрана инвентаря — встроенная панель (Q/E в ней выбирают предмет первой кнопки).
- Новый предмет сам встаёт на свободную кнопку: на первую, если она пуста, иначе на вторую (`inventory.autoEquipFirst`, `inventory.autoEquipSecond`).
- Меч (X) и щит (V) — на своих клавишах, сила (перчатка) работает сама.
- HUD: элемент *Item box* показывает первую или вторую кнопку (поле *Item button*); классический HUD — обе (вторая под первой).

## Закопанный клад и бомбо-стрелы (с 0.30.0)

- **Клад.** `Zelda: Create Chest` с галочкой **Buried**: вместо сундука — невидимое место, где лежит предмет. Лопата, ударившая в это место, выкапывает его (предмет выдаётся, как из сундука, с сообщением «Получено…»), ямка остаётся и сохраняется в прогрессе — второй раз не выкопать. В редакторе такое место нарисовано бледной ямкой с подписью `buried: …`.
- **Бомбо-стрела.** Поставьте лук и бомбы на две кнопки предметов (C и B) и нажмите обе вместе. Если на кнопках лук и бомбы, одиночное нажатие одной из них срабатывает с задержкой `comboMs` (100 мс) — чтобы успеть нажать вторую.

## Подбор бомбы (с 0.31.0)

Положенную бомбу можно поднять клавишей действия (Z), как горшок, и бросить второй Z: она летит на дальность броска (`items.thrown.range`) или до стены и лежит там, пока не догорит фитиль. Фитиль горит и в руках: не бросите вовремя — взорвётся над головой (и ранит, если `combat.bombsHurtPlayer`). Удар по игроку роняет бомбу к ногам.

## Свой предмет без кода

`Zelda: Define Item` — поля формы:

| Поле | Смысл |
|---|---|
| Item, Name, Icon | какой из своих предметов (Custom item 1–4), название в сообщениях, иконка (картинка PS Maker) |
| Uses, Cost | что тратит одно использование (список: ничего, рупии, бомбы, стрелы, магия, ключи) и сколько |
| Damage, Damage type | урон выстрела; тип урона (список) — враги могут быть к нему устойчивы |
| Area attack | бить всё вокруг игрока вместо выстрела |
| Stun (ms) | оглушить врагов при попадании |
| Heal | восстановить половинок сердца (предмет становится лечебным) |
| Give now | сразу выдать игроку |

Что получится: *Heal* > 0 — лечебный предмет; иначе *Damage* > 0 — выстрел (или удар вокруг с *Area attack*); иначе — сюжетный предмет для условий *When player has*. Свой предмет выбирается как Custom item 1–4 во всех списках предметов (Give Item, сундуки, правила).

Пример «Ледяной жезл»: Item *Custom item 1*, Name `Ледяной жезл`, Uses *Magic*, Cost `4`, Damage `3`, Damage type *ice*, Stun `1200`.

Из кода доступны все поля (скорость и дальность выстрела, пробивание, эффекты `restoreMagic`, `setFlag`, `emit`, перевод названия): `ZeldaMakerToolkit.defineItem({ id, name: { en, ru }, effect: "projectile", projectile: { speed, range, pierce } })`.

Свой ресурс (например, «семена») пока доступен только из кода: `ZeldaMakerToolkit.configure({ inventory: { capacities: { seeds: 50 } } })` и `ZeldaMakerToolkit.defineItem({ resource: "seeds", ... })`. Названия ресурсов для сообщений — через строки `item.seeds.name` (`ZeldaMakerToolkit.extendStrings`) или поле `name` у предмета с `"stackable": true`.

## Предмет из кода

```js
ZeldaMakerToolkit.registerItem({
  id: "pegasus_dash",
  icon: "icon_generic",
  quickUse: true,
  cooldownMs: 800,
  use(ctx) {
    // ctx: { session, facing, x, y, frontX, frontY, dirX, dirY }
    ctx.session.player.moveWithCollision(ctx.dirX * 32, ctx.dirY * 32);
    return true; // или Entity, чтобы учитывать maxActive
  },
});
```

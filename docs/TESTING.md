## Ручные сценарии в PS Maker

Выполнить после установки `dist/zelda-maker-toolkit.ps-maker.js` в `/plugins`. Результат каждого шага сверить с ожидаемым; при расхождении приложить вывод консоли браузера (`[ZeldaMakerToolkit]`).

| ID | Сценарий | Ожидаемо |
|---|---|---|
| M-01 | Открыть проект, добавить событие: в списке есть действия `Zelda: …` | 43 действия с формами параметров. Если списка нет — редактор ожидает другое поле (`actions` экспортируется тоже); сообщить версию PS Maker |
| M-02 | On-load: `Zelda: Start Toolkit` (Map ID `test`), запустить playtest | В консоли нет ошибок; в левом верхнем углу HUD с сердцами |
| M-03 | `Zelda: Create Enemy` с Position | Слизень появляется в выбранной точке. Если смещён в ~16 раз — Position в тайлах: `{"world":{"positionUnits":"tiles"}}` |
| M-04 | Подойти к врагу, нажать X | Меч виден в направлении взгляда, у врага −2 HP (F9: красный хитбокс), враг отлетает; во время удара игрок не двигается |
| M-05 | Дать врагу коснуться игрока | −1 HP, игрок отлетает и мигает ~1 с, повторного урона нет |
| M-06 | Стены карты | Враги и снаряды не проходят сквозь коллизии карты. Если проходят — в консоли предупреждение `No Arcade static bodies…`: коллизии PS Maker устроены иначе |
| M-07 | `Use NPC` у `Zelda: Create Enemy` | NPC становится врагом. Если нет — предупреждение `NPC "…" was not found`; сообщить, как выглядит значение параметра |
| M-08 | Сундук + дверь + ключ, смена карты туда-обратно | Сундук остаётся открытым, дверь — открытой |
| M-09 | Удалить плагин из `/plugins`, запустить проект без действий `Zelda:` | Проект работает как раньше. (С действиями `Zelda:` редактор, вероятно, покажет отсутствующий плагин) |
| M-10 | Открыть диалог PS Maker во время боя | Если враги продолжают атаковать во время диалога — оборачивайте диалог в `Zelda: Pause Combat` true/false |
| M-11 | Экспорт Web/Itch.io | Игра работает, сохранения Toolkit в `localStorage` |
| M-12 | Клавиша Z рядом с NPC и сундуком | Проверить, что взаимодействие PS Maker и открытие сундука не конфликтуют; при конфликте сменить `controls.action` |
| M-13 | Мобильное устройство | Тач-кнопка PS Maker не вызывает меч (ограничение API); сообщить, если нужна поддержка |

## Как писать новые тесты

- Логика: `tests/helpers/fakeHost.ts` → `createRig(config)` даёт `Toolkit`, `FakeHost` (игрок-бокс, стены, ввод) и `Session`; `rig.host.walk(dx, dy)` имитирует движение PS Maker, `rig.host.input.tap("sword")` — нажатие, `rig.run(ms)` — время.
- Phaser-адаптер: `tests/helpers/fakePhaser.ts` (эмиттеры со счётчиками) или интеграционный тест.

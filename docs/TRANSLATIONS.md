# Переводы: игра на нескольких языках без правки текстов

С 0.33.0. Идея — как у Non-Destructive Localization (Sang Hendrix) для RPG Maker MZ/MV: тексты в редакторе остаются как написаны, а перевод лежит отдельно, в таблице «строка — текст, столбец — язык», которую можно выгрузить в CSV для Excel или Google Sheets и загрузить обратно. Возможности взяты со скриншота страницы плагина; код и данные плагина не использовались.

## Как начать

1. Поставьте `Zelda: Translations` в «Map start» **одной** карты (обычно первой, рядом с `Zelda: UI Layout`). Таблица в проекте одна — первая по порядку карт; она работает на всех картах.
2. Откройте действие. Справа появится панель **Zelda translation sheet**.
3. Первый язык — **source**, язык, на котором написан проект. Нажмите на его код, чтобы поменять код или название (например `ru` и «Русский»).
4. Добавьте языки: код (`en`, `de`, `ja`, `zh-CN`…) и **+ Add**.
5. **Find texts in the project** собирает все тексты проекта. Повторный поиск после правок в проекте добавляет новые тексты и сохраняет переводы. Тексты, которых больше нет в проекте, остаются в таблице с пометкой ✗ (кнопка **Remove N unused** убирает их).
6. Переводите прямо в таблице или через CSV. Пустая ячейка — перевода нет, игра покажет текст как написан (такие ячейки обведены красным).

Таблица хранится в поле *Translation data* самого действия (пишет панель, руками не править), то есть внутри проекта PS Maker, и попадает в экспорт игры.

## Что переводится

| Где | Что | Тип строки |
|---|---|---|
| PS Maker → `Dialogue` | страницы текста (строки подряд — одна строка таблицы), имена «Имя: текст» и `@name "…"` | `text`, `name` |
| PS Maker → `Choices` | вопрос и варианты ответа | `text` |
| PS Maker → `Show Image`, `Change Image` | какую картинку показать вместо этой (по имени из *Images*) | `image` |
| `Zelda: Show Message`, табличка `Create Object`, `Add Rule` / `Run Actions` / `Create Switch Sequence` (*Message*) | текст | `text` |
| `Zelda: Dialogue` | реплика, ответы 1–4; *Speaker* | `text`, `name` |
| `Zelda: Define Item` | название предмета | `text` |
| `Zelda: UI Layout` | тексты, надписи кнопок и полос; картинки элементов и кнопок (по имени, как у `image`) | `text` |
| Строки самого Toolkit | «- LIFE -», «Получено: …», названия предметов и клавиш… (ключ в столбце *where*) | `toolkit` |

Команды диалога (`@portrait`, `@wait`, `{@variable …}`, `{@run_action …}`…) остаются на месте. В переводе можно переносить строки (новая строка) и даже разбивать на страницы (пустая строка). Если строка перевода начинается с `@` или выглядит как «Имя: текст», Toolkit экранирует её `\`, чтобы PS Maker не принял её за команду или за имя.

Тексты со значениями `{rupees}`, `{language}` переводятся целиком: оставьте `{…}` в переводе. Тексты только из значений и цифр в таблицу не попадают.

Строки Toolkit: в столбцах `en` и `ru` CSV показывает собственный текст Toolkit (для справки); перевод, совпадающий с ним, не сохраняется. Строку Toolkit можно переопределить и на языке-источнике.

**Не переводится:** имя NPC в `@name <npc-id>` (это имя персонажа, а не текст диалога), UI-компоненты PS Maker (*Add UI*), меню опций и загрузки PS Maker, тексты в переменных.

## Языки

У каждого языка в панели (щелчок по его коду):
- **Name** — как язык называется для игрока (`{language}` в макете UI);
- **Dialogue layout** — макет диалога PS Maker для этого языка (*Game UI → Dialog layouts*): свой шрифт и размер, например для японского. Во всех диалогах на этом языке все `@dialogue_layout` указывают на него;
- **Choices layout** — макет выбора PS Maker;
- **Toolkit font** — шрифт проекта для текстов Toolkit (HUD, экраны, сообщения);
- **Remove language** (кроме источника) — удалить язык и его переводы (Undo возвращает).

### Язык игры

- `Zelda: Start Toolkit` → *Language*: **Auto** — язык браузера или системы, если он есть в таблице, иначе язык-источник. *English* / *Русский* — этот язык.
- Кнопка экрана в дизайнере: *When pressed* → **Change the language**. Поле *Language*: код языка, пусто — следующий язык таблицы по кругу. Выбор игрока хранится в браузере (для каждого проекта) и важнее *Language* у `Start Toolkit`.
- `{language}` в тексте макета — название текущего языка: кнопка «Язык: {language}».
- Без таблицы всё как раньше: тексты проекта как написаны, строки Toolkit на английском или русском.

## CSV

- **Export CSV** — файл `<проект> translations.csv`. В редакторе PS Maker на компьютере открывается его окно сохранения, в браузере файл скачивается. Столбцы: `type`, `where`, затем язык-источник и остальные языки. Файл в UTF-8 с BOM (Excel открывает кириллицу правильно).
- **Separator** — *Auto*: «;» там, где десятичный знак — запятая (ru, de, fr…: так ждёт Excel), иначе «,». Или явно «,» или «;».
- **Import CSV** — разделитель определяется по первой строке. Переводы строк из файла заменяют текущие, новые столбцы-языки добавляются. Строки, которых нет в таблице, добавляются, остальные строки таблицы не трогаются. Первый столбец языка должен быть языком-источником.
- Перед поиском текстов и импортом панель сохраняет копию таблицы в браузере (пять последних, список **Backups…**). Кроме того, есть **Undo** и резервные копии проекта самого PS Maker.

## Как это работает

- Строка таблицы находится по исходному тексту: в редакторе ничего не добавляется к текстам. Если текст поправили, это новая строка, а старая остаётся неиспользуемой с прежним переводом, его можно скопировать.
- Действия PS Maker (*Dialogue*, *Choices*, *Show Image*, *Change Image*) переводятся в момент выполнения: проект при этом не меняется. Как именно — [ENGINE_AUDIT.md, раздел 27](ENGINE_AUDIT.md#27-переводы-033).
- Диалоги PS Maker переводятся на картах, сцены которых уже созданы, когда запускается Toolkit (`Zelda: Start Toolkit` на этой или любой другой карте). На карте без `Start Toolkit`, впервые открытой после него, диалоги показываются как написаны.

## Чего нет по сравнению с плагином для RPG Maker

- Подсветки строки таблицы по текущей реплике во время игры: игра в PS Maker запускается отдельно от редактора, и панель её не видит.
- Своего размера шрифта для текстов Toolkit на языке: размер задаётся в макете; для PS Maker — через *Dialogue layout* языка.

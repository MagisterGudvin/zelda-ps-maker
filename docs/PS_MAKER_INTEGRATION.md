# Связка с PS Maker 1.x

Как сочетать Toolkit со штатными возможностями PS Maker 1.0–1.2 (титульный экран, сохранения, UI, диалоги, NPC, звук). Плагин не может читать переменные, условия, инвентарь и сохранения PS Maker (API плагинов этого не даёт), поэтому связь строится на событиях PS Maker, которые вызывают действия Toolkit.

## Титульный экран и сохранения

В PS Maker 1.0 появились UI-компоненты и титульный экран, в 1.1 — сохранение игры во время событий. Прогресс Toolkit (здоровье, предметы, сундуки, двери, подземелья) хранится отдельно, поэтому повесьте действия Toolkit на те же кнопки:

| Кнопка / событие PS Maker | Добавьте действие Toolkit |
|---|---|
| «Новая игра» | `Zelda: Reset Progress` (New game = true) |
| «Продолжить» / загрузка сохранения | `Zelda: Load Progress` (тот же слот) |
| Меню «Сохранить» / точка сохранения | `Zelda: Save Progress` |

Сундуки, двери, новые предметы и завершение подземелий дополнительно сохраняются автоматически (`save.autoSave`). Номер слота Toolkit можно сделать равным номеру слота PS Maker (`default`, `slot1`…).

## Карты

- В событиях загрузки (Map start) **каждой** карты первым действием — `Zelda: Start Toolkit` с уникальным *Map ID*. По нему запоминаются объекты этой карты.
- Переход между картами (штатное действие смены карты) ничего дополнительно не требует: Toolkit отключается от старой карты и запускается заново на новой, прогресс сохраняется.

## NPC

- `Zelda: Enemy From NPC` берёт NPC, который **уже стоит на карте**: штатное действие появления NPC (Spawned NPC) должно идти раньше. Враг использует спрайт и анимации этого NPC.
- С PS Maker 1.1 у NPC есть коллизии. Toolkit тоже считает их препятствиями (`world.npcsBlock`): враги и снаряды не проходят сквозь NPC.

## Диалоги и сцены

Если во время диалога PS Maker враги продолжают двигаться, оберните диалог действиями `Zelda: Pause Combat` (true) и `Zelda: Pause Combat` (false). С параллельными событиями PS Maker 1.1 это особенно важно для катсцен.

## Звук

С PS Maker 1.1 звуковые ассеты стали полноценными. `Zelda: Set Sound` назначает звук моменту боя: `swordSwing`, `spinAttack`, `enemyHurt`, `enemyDefeated`, `playerHurt`, `playerDie`, `shieldBlock`, `bombExplode`, `objectBreak`, `pickup`, `itemGet`, `chestOpen`, `doorUnlock`, `puzzleSolved`. Если выбор звука в форме не сработал, впишите ключ или путь к файлу в *Sound key or URL*. Общая громкость и отключение: `{"audio":{"volume":0.7}}`, `{"audio":{"enabled":false}}`.

## Интерфейс и боевая система PS Maker

- Боевая система PS Maker 1.0 — пошаговая, собирается из UI-кнопок и событий. Бой Toolkit идёт в реальном времени прямо на карте. Их можно использовать в одной игре, но для разных сцен.
- HUD Toolkit рисуется поверх UI PS Maker и не заходит в правый верхний угол (шестерёнка настроек), см. `ui.safeArea`. Если вы строите свой интерфейс на UI-компонентах PS Maker, снимите галочку *Show HUD* у `Zelda: Start Toolkit`. Значения Toolkit в переменные PS Maker не передаются.

## Проверка

Если что-то не появилось или ведёт себя странно — `Zelda: Debug` (Diagnostics) или F10: на экране видно, какие параметры передал PS Maker, где созданы враги и объекты, какие были предупреждения.
